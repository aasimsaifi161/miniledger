# MiniLedger - Mobile App

This directory contains the Expo / React Native mobile client for MiniLedger.

For full project documentation and setup instructions, please refer to the root [README.md](../README.md).

## Available Commands

- `npm install` - Install dependencies
- `npx expo start` - Start Expo development server
- `npx tsc --noEmit` - TypeScript type checking
- `npx expo lint` - Lint source code
